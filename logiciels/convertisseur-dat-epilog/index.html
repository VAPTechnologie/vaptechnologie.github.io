Convertisseur DAT Epilog Laser vers Job Manager

Convertissez vos anciens fichiers DAT Epilog Laser vers Job Manager et retrouvez vos paramètres de gravure. Cet utilitaire gratuit pour Windows 10 et 11 s’adresse aux utilisateurs de machines Epilog Laser.

Interface du convertisseur

Les nouveautés de la V2.1

Le convertisseur se choisit maintenant en mode clair ou en mode sombre, grâce à un bouton dans le bandeau. Le changement est immédiat, sans redémarrage, et le choix est mémorisé au lancement suivant. La conversion ne change pas : mêmes réglages produits, mêmes contrôles.

Fonctionnalités

  • Sélection des anciens fichiers DAT et option de sous-dossiers
  • Choix de la sauvegarde Job Manager
  • Sélection de la machine de destination
  • Options de conversion configurables
  • Conservation des fichiers d'origine

Mode d'emploi

1. Dans Job Manager, créez une sauvegarde de la base de données.

2. Dans le convertisseur, sélectionnez le dossier contenant les anciens fichiers DAT.

3. Sélectionnez la sauvegarde Job Manager et choisissez la machine de destination.

4. Vérifiez les options, puis lancez la conversion.

Pour la procédure complète et les précautions, consultez également le README officiel du logiciel ↗.
