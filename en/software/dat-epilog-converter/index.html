Epilog Laser DAT to Job Manager Converter

Convert your legacy Epilog Laser DAT files to Job Manager and recover your engraving settings. This free utility for Windows 10 and 11 is designed for Epilog Laser machine users.

Release history ↗

Converter interface

What’s new in V2.1

The converter can now be switched between light and dark mode with a button in the header bar. The change is instant, with no restart, and your choice is remembered next time. Conversion is unchanged: same settings produced, same checks.

Features

  • Select legacy DAT files, with an option to include subfolders
  • Select a Job Manager backup
  • Select the destination machine
  • Configure conversion options
  • Keep your original files unchanged

How to use

1. In Job Manager, create a database backup.

2. In the converter, select the folder containing your legacy DAT files.

3. Select the Job Manager backup and choose the destination machine.

4. Review the options, then start the conversion.

For the full procedure and precautions, also see the official software README ↗.
